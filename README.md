# LiftVault | Powerlifting Training App

Welcome to **LiftVault**, a high-performance training companion built with Next.js, Tailwind CSS, and Genkit AI.

## 🚀 Quick Start
To view your application, look at the **Preview Window** on the right side of your screen. Any code changes you save will automatically refresh the preview.

## ✨ Key Features
- **Smart Dashboard**: Real-time tracking of your estimated 1-Rep Max (1RM) for Squat, Bench, and Deadlift.
- **Custom Programming**: Build a 3-day split with automated %-based 1RM calculations and visual progression.
- **Dynamic Workout Log**: Log sets and reps with an integrated **Plate Visualizer** to help you load the bar correctly.
- **Performance Analytics**: Deep dive into volume, strength trends, and lift distribution.
- **Coach AI**: Use the **AI Insights** tab to get personalized training adjustments and technical form tips.

## 📦 Exporting & Deployment
1. **Download Source**: Use the **Download** button in the top toolbar of Firebase Studio to export your project as a `.zip` file.
2. **GitHub Integration**: Connect your project to a GitHub repository to version control your code and collaborate.
3. **Firebase App Hosting**: This project is pre-configured with `apphosting.yaml`. You can deploy it by connecting your GitHub repo to **Firebase App Hosting** in the Firebase Console for automated builds and deployments.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + ShadCN UI
- **AI**: Genkit with Google Gemini
- **Database/Auth**: Firebase (Ready for integration)
